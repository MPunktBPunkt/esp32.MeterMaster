ℹ️Hinweise

Bei aktivem Alarm blinkt die rote LED und das OLED zeigt !ALM.
Der Alarm wird nach jedem Datenabruf geprüft (Intervall: Einstellungen).

🔵Bluetooth / BLE
🔵
In Vorbereitung

BLE benötigt ca. 500 KB zusätzlichen Flash-Speicher.
Für BLE-Support in Arduino IDE unter
Tools → Partition Scheme wählen:

Huge APP (3MB No OTA)

Danach kann BLE-Scan aktiviert werden.

🔮Geplante BLE-Features

• BLE-Scan: Geräte in der Nähe anzeigen
• Xiaomi LYWSD03MMC Thermometer direkt auslesen
• Temperatur/Luftfeuchtigkeit auf OLED anzeigen
• BLE → ioBroker Gateway-Funktion
• iBeacon-Erkennung für Präsenz-Automation
